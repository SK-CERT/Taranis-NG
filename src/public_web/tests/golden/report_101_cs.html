[TLP:CLEAR] Critical vulnerabilities in Apache products

Several vulnerabilities were published, see [1].

Apache HTTP Server: request smuggling (CVE-2025-1111)
CVSS 9.8 (Critical)

An attacker can smuggle requests [2] and bypass ACLs [1].

Zranitelnost se nachází v produktech:

  • Apache HTTP Server (linux) ve verzích >=2.4.0 AND <2.4.65
  • Apache mod_proxy ve verzích (<2.4.65) OR (3.0.0-beta)
  • Apache Traffic Server

Update to version 2.4.65 or later [1].

CVSS: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H

IOC: 198.51.100.7, evil.example.net

Více informací:

  • CVE-2025-1111 na cve.org, NVD, GitHub, CIRCL.LU, Debian, Ubuntu, Red Hat, SUSE
  • CVE-2025-1112 na cve.org, NVD, GitHub, CIRCL.LU, Debian, Ubuntu, Red Hat, SUSE
  • CWE-444: Inconsistent Interpretation of HTTP Requests na cwe.mitre.org
  • CWE-20 na cwe.mitre.org

Zranitelnost byla veřejně oznámena 10. 9. 2025. Naposledy byl tento report aktualizován 12. 9. 2025.

Zranitelnost se nachází v produktu Apache Tomcat (windows) ve verzích <10.1.40.

Více informací:

Zranitelnost byla veřejně oznámena 11. 9. 2025.
